# ЛИМИТ — PWA учёта трат

Строгое чёрно-белое приложение с тёплым акцентом. Данные хранятся только в браузере (`localStorage`).

## Запуск

Нужен любой статический сервер (PWA и камера/файлы надёжнее работают не через `file://`):

```bash
cd limit-pwa
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. На телефоне — «Добавить на экран Домой».

## Вкладки

1. **Главная** — дневной лимит, пул месяца, история пополнений и трат.
2. **Обязательно** — цели накоплений (сумма или %, период, скрытый режим).
3. **Статистика** — расход по дням, распределение поступлений, категории.
4. **Копилка** — процентное распределение остатка.
5. **Прочее** — долги (PIN из настроек), шкала нагрузки, приоритет 1–5.

Свайп влево по записи или карточке — удаление с подтверждением.

## Алгоритм зарплаты

1. `дневной лимит × дни месяца` → пул Главной.
2. От остатка до 50% → «Прочее», но не больше суммы потребностей карточек.
3. Далее видимые карточки «Обязательно».
4. Остаток — видимые карточки «Копилки» по их %.

Аванс и доп. доход: шаг 2, затем сразу копилка (без дневного пула и «Обязательно»).
